# Attendance-Management-System

#### 介绍
本项目为考勤管理系统，分别有学生，老师两个身份进行登录，学生可以查看自己的考勤信息、用户信息以及修改密码；老师可以添加、修改、查询和统计考勤记录、修改密码等功能。
